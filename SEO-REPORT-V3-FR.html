Tracking & Mesure — Smoking Gun

Blocage stratégique Nouveau 9 avril

Diagnostic confirmé sans accès GA4 : le tag GA4 est bloqué par défaut pour tous les visiteurs européens via la configuration Consent Mode injectée par Site Kit.

🚨 Diagnostic confirmé sans accès GA4 : L'investigation directe du code de la home de naoenergy.ch (curl + inspection HTML) confirme à 100 % que le tag GA4 est bloqué par défaut pour tous les visiteurs européens (CH inclus) via la configuration Consent Mode injectée par Site Kit. Tant que ce problème n'est pas résolu, aucune stratégie SEO ne peut être pilotée ni mesurée. C'est le prérequis bloquant absolu.

🔧 Smoking Gun #1 — Consent Mode bloque GA4 par défaut

Code injecté par Site Kit dans le <head> de chaque page (lignes 11-18 du HTML) :

gtag('consent', 'default', {
  "ad_personalization":     "denied",
  "ad_storage":             "denied",
  "ad_user_data":           "denied",
  "analytics_storage":      "denied",   // ← GA4 BLOQUÉ par défaut
  "functionality_storage":  "denied",
  "security_storage":       "denied",
  "personalization_storage":"denied",
  "region": ["AT","BE","BG","CH","CY","CZ","DE","DK","EE",
             "ES","FI","FR","GB","GR","HR","HU","IE","IS","IT",
             "LI","LT","LU","LV","MT","NL","NO","PL","PT","RO",
             "SE","SI","SK"],   // ← 31 pays EU/EEE + Suisse
  "wait_for_update": 500
});
ParamètreEffet
analytics_storage: deniedGA4 ne peut PAS collecter de pageview tant que l'utilisateur n'a pas cliqué "Accepter" sur la bannière Complianz
region: [..CH, FR, DE, BE..]S'applique à tous les visiteurs des 31 pays EU/EEE + Suisse
wait_for_update: 500gtag attend 500 ms le consentement — si pas de clic, le pageview est perdu définitivement
Bannière ComplianzType cmplz-bottom-right ... optin (opt-in discret en bas à droite, taux d'acceptation typique 15-25 %)

⚙️ Mécanisme exact — Pourquoi GA4 ne voit que les bots

🇨🇭
Visiteur réel suisse / européen
1. Charge la page
2. gtag default = denied (CH dans la région)
3. Bannière Complianz s'affiche en bas à droite
4. Visiteur ferme/ignore (~80 % le font)
5. analytics_storage reste denied
6. ❌ Pageview NON envoyé à GA4
7. Visiteur invisible dans GA4
🤖
Bot US / Chine / Singapour / Tunisie
1. Charge la page
2. gtag default = denied
3. Bot ignore la bannière
4. Région du bot ∉ EU/CH
5. → Consent Mode ne s'applique pas
6. ✅ Pageview envoyé normalement
7. Bot visible dans GA4
Conséquence
C'est exactement pourquoi GA4 montre 83 % USA + Chine + Singapour + Tunisie et seulement 17 % "Autres" (qui contient la Suisse + le reste de l'Europe). Les vrais visiteurs cibles sont devenus invisibles, les bots sont devenus la majorité.

🚨 Smoking Gun #2 — Double tracking GA4 détecté

L'inspection du HTML révèle deux propriétés GA4 chargées en parallèle par deux plugins différents :

IDTypeSource / PluginPosition dans le HTML
GT-WBK8XSPWGoogle Tag (nouveau format)Site Kit by GoogleLigne 246 + config
G-7G5KELWH87GA4 Measurement IDGA Google Analytics (plugin Jeff Starr)Ligne 259 + config
AW-11093980890Google Ads conversionSite Kit (lié à GT-WBK8XSPW)Ligne 253
Problème
Deux propriétés GA4 distinctes reçoivent (ou ne reçoivent pas) les mêmes événements simultanément. Personne ne sait laquelle est la "vraie" propriété officielle, ni si Site Kit affiche les données de l'une ou de l'autre. Cela crée de la confusion sur "quel chiffre regarder" et fragmente potentiellement les données de conversion.
Action
Décider quelle propriété GA4 garder (probablement GT-WBK8XSPW de Site Kit puisque c'est celle liée à Google Ads), puis désactiver le plugin GA Google Analytics ou retirer son ID de la config.

🔧 Plan de fix — 3 options proposées

A
Option A — Consent Mode v2 Advanced + Behavior Modeling
Solution recommandée — 100 % conforme RGPD.

Résultat attendu : restauration de ~70-90 % du trafic actuellement perdu dans GA4, sans toucher au site ni à la bannière de consentement.
Risque : nul · RGPD : OK
B
Option B — Bannière de consentement plus visible
Améliorer le taux d'acceptation cookies en rendant la bannière plus visible.

Résultat attendu : taux d'acceptation 40-70 % au lieu de 15-25 % actuels.

Inconvénient : impact UX potentiellement négatif.
Risque : UX · RGPD : OK
C
Option C — Search Console comme source de vérité
Utiliser Search Console comme métrique principale (non affecté par le consentement cookies).

Données fiables disponibles : 2 600 clics / 155 K impressions sur 90 jours.

Inconvénient : perte d'attribution Paid Search vs Organic vs Direct et impossibilité de mesurer les conversions.
Risque : aveugle au funnel
Diagnostic établi le 9 avril 2026 par inspection directe du HTML rendu de https://naoenergy.ch/ (curl + grep des balises gtag/Complianz). Aucun accès direct à GA4 ou Search Console nécessaire pour ce diagnostic. La validation finale et l'application du fix nécessiteront un accès Lecteur GA4 + Restreint Search Console.
