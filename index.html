CRITIQUE
Inondation massive de 404 /meta.json par les robots Facebook
Les journaux du plugin Redirection montrent des milliers de requêtes 404 pour /meta.json provenant de facebookexternalhit/1.1. Cela indique que le robot d'exploration de Facebook recherche des métadonnées inexistantes, probablement déclenché par des liens partagés.
Correction : Créer un fichier /meta.json valide à la racine du site, ou ajouter une règle de redirection/blocage pour ce chemin dans le plugin Redirection.

💡 Plan d'actions prioritaires

▼

🔴 Critique — À corriger cette semaine

1. Activer l'optimisation JS de WP Rocket

Aller dans WP Rocket → Optimisation des fichiers → JavaScript. Activer : Minifier JS, Différer le chargement JS et Retarder l'exécution JS. Tester minutieusement après chaque modification.

Impact : Core Web Vitals TBT/INP

2. Corriger l'optimisation des images

Passer au plan payant Imagify (5,99 $/mois) ou basculer vers ShortPixel gratuit. Générer les 81 versions WebP manquantes. Activer "Ajouter les dimensions d'images manquantes" dans WP Rocket. Ajouter le texte alt aux 18 images.

Impact : LCP + CLS + SEO Images

3. Corriger les 9 864 erreurs 404

Créer un fichier /meta.json valide ou ajouter une règle de redirection. Purger les anciens journaux 404 dans le plugin Redirection. Surveiller les nouveaux motifs.

Impact : Budget de crawl + Charge serveur

4. Corriger les en-têtes de sécurité

Ajouter CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy et Permissions-Policy via la configuration serveur ou un CDN. Envisager l'ajout d'un CDN (Cloudflare gratuit).

Impact : Sécurité + Signaux de confiance

5. Mettre à jour le thème & les extensions

Mettre à jour le thème en attente (critique pour la sécurité). Mettre à jour Polylang Pro 3.6.6 → 3.8.1. Supprimer les 3 extensions désactivées. Passer PHP de 8.1 à 8.2+.

Impact : Sécurité + Performance

🟠 Haute priorité — À corriger sous 2 semaines

6. Activer la minification CSS + Supprimer le CSS inutilisé

WP Rocket → Optimisation des fichiers → CSS. Activer la minification et passer du CSS async à "Supprimer le CSS inutilisé" comme le recommande WP Rocket.

7. Activer le préchargement des polices & l'hébergement local des Google Fonts

WP Rocket → Médias. Activer les deux options pour réduire le LCP et éliminer les requêtes de polices bloquant le rendu vers les serveurs Google.

8. Ajouter les schemas LocalBusiness + Service

Ajouter le schema LocalBusiness avec adresse, téléphone, horaires. Ajouter le schema Service pour les panneaux solaires, pompes à chaleur, bornes de recharge. Utiliser Yoast Premium ou du JSON-LD personnalisé via le plugin Code Snippets.

9. Compléter le profil Organisation dans Yoast

Remplir la description de l'organisation, l'e-mail et le profil Twitter/X dans Yoast SEO → Représentation du site. Cela enrichit la sortie schema pour le Knowledge Graph de Google.

10. Corriger le maillage interne (18 pages orphelines)

Ajouter des liens internes depuis les pages de contenu pertinentes vers les 18 pages orphelines identifiées. Corriger les 36 liens sans texte d'ancrage.

🔵 Priorité moyenne — À corriger sous 1 mois

11. Créer /llms.txt pour la recherche IA

Créer llms.txt à la racine du site avec la description du site et les liens vers les pages clés. Gérer les robots IA (GPTBot, ClaudeBot, etc.) dans le robots.txt.

12. Envisager l'expansion multilingue

Polylang Pro est déjà installé. Ajouter du contenu en allemand (de_CH) débloquerait le marché de Suisse alémanique. Même les pages d'atterrissage clés généreraient des balises hreflang.

13. Améliorer la lisibilité du contenu

Score Flesch 35,5 (très difficile). Raccourcir les phrases à 15-20 mots. Fractionner les longs paragraphes. Simplifier le vocabulaire technique pour un public plus large.

14. Connecter Google Site Kit + Ajouter les indices Preconnect

Se connecter à Site Kit pour accéder aux données Search Console dans le tableau de bord WP. Ajouter des indices preconnect pour Google Fonts, Analytics et les autres ressources tierces.
